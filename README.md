# Personal Site

Simple static personal page ready for GitHub Pages.

## Files
- `index.html`
- `styles.css`

## Customize
1. Edit `index.html` and replace:
   - `Your Name`
   - `your-username`
   - `you@example.com`
   - project descriptions

## Deploy on GitHub Pages
1. Create a GitHub repository (for user/organization site, use `<username>.github.io`).
2. Push this folder's contents to the repository root.
3. In GitHub: **Settings → Pages**.
4. Under **Build and deployment**, choose:
   - **Source**: `Deploy from a branch`
   - **Branch**: `main` (or `master`) and `/ (root)`
5. Save and wait for deployment.

Your site will be available at:
- `https://<username>.github.io/` (if repo name is `<username>.github.io`)
- `https://<username>.github.io/<repo-name>/` (for project repositories)
